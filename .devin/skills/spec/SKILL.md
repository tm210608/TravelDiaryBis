# /spec <feature>

Modo planificacion: no escribas codigo.
1. Lee `AGENTS.md`, `docs/STATE.md`, `docs/ARCHITECTURE.md` y `docs/specs/_TEMPLATE.md` (nada mas, salvo grep puntual).
2. Haz 3-5 preguntas incomodas al usuario (ambiguedades, alcance, estados, permisos, edge cases).
3. Crea `docs/specs/<feature>/SPEC.md` desde la plantilla: criterios testeables y sin ambiguedad, fuera de alcance, UI states, navegacion, archivos por capa, plan de tests.
4. Pide aprobacion explicita. No implementes.
